# AgriDirect - Bring Farm to Table 🥦🚜

AgriDirect is an e-commerce platform designed to connect farmers directly with consumers, eliminating middlemen and ensuring fresh produce at fair prices. Built with simplicity and functionality in mind, this project is part of a practical demonstration of frontend development using HTML, CSS, and JavaScript.
